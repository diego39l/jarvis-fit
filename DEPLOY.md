# Publicação Jarvis Fit

1. Verifique o workflow **Build PWA** no GitHub Actions.
2. Execute `npm install` / `npm run build` localmente.
3. Configure o GitHub Pages com deploy de `dist/` via workflow após validar o build.
4. Para instalar no Android, acesse a URL HTTPS no Chrome e use **Instalar aplicativo**.

O repositório privado não implica site privado: revise a visibilidade da hospedagem antes de publicar.
